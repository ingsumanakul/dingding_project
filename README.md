# DING DING THE CAT 🐈‍⬛

A little black-and-white cat who loves to peek in and say hi.

**▶ Play: https://ingsumanakul.github.io/dingding_project/**

- 🎰 **Gacha**: spin the capsule machine and collect all 68 DING DINGs (one of them is a Secret 👀)
- 🧩 **Quiz**: answer 5 questions and find out which DING DING you are, then save the card for your story
- 🗂 **Collection**: every DING DING you've found, with its animation
- 🌏 English, ไทย and 日本語

Every DING DING, still and animated, is drawn and animated by Sumana “Ing” Sumanakul of INGINGE DESIGN.
The website was vibe coded with [Claude Code](https://claude.com/claude-code), using Claude Fable 5.2 and Claude Opus 5.5.

## Made with

Plain HTML, CSS and JavaScript, no framework and no build step, hosted on GitHub Pages.
Your collection is saved in your own browser (`localStorage`), so there are no accounts and no server.
